# P1-NAT-001 — Win32 helper ABI, toolchain, and threat contract

- Owner on dispatch: Root-assigned native/security worker after a CPU slot is free.
- Objective: freeze the narrow versioned Win32 helper ABI and toolchain before any native implementation, covering only operations ADR-003 forbids Electron/Node from performing safely.
- Product boundary: protocol/threat contract and hostile fixtures only. The helper has no generic command, shell, network, download, Comfy queue, `/prompt`, inference or media-generation surface.
- Dependencies: Root-accepted P0-ARC-005, P0-ARC-010 and P0-CON-001.
- Allowed writes: `native/win32-helper/spec/**`, `native/win32-helper/include/**`, `tests/fixtures/native-helper/protocol/**`, `docs/adr/ADR-013-win32-helper-protocol.md`.
- Forbidden writes: implementation sources/binaries, Electron app, root/production lockfiles, registry, WBS, schemas, installer/runtime/model files and external paths.
- Locks: none.
- Required contract: exact compiler/SDK/architecture plan; ABI and framing version; bounded message length; canonical encoding; request/response correlation; caller/process/build identity; operation allowlist; typed errors; cancellation/timeouts; no ambient paths; handle/volume/reparse/Job/signature trust inputs; downgrade/replay/truncation/confusion rejection; unsigned internal versus signed release state.
- Required negative fixtures: unknown opcode/version/field, oversized/truncated frame, duplicate ID, replay, wrong parent/build/helper hash, path encoding ambiguity, arbitrary executable/argument/network request, queue/generation request and signing-state promotion.
- Acceptance commands from repository root:

  ```powershell
  node --check .\tests\fixtures\native-helper\protocol\validate.mjs
  node .\tests\fixtures\native-helper\protocol\validate.mjs
  powershell -NoProfile -ExecutionPolicy Bypass -File .\tasks\validate_wbs.ps1
  ```

  Expected: exit `0`; deterministic valid/hostile counts, exact ABI digest and no forbidden operation; WBS stays green. Run validator twice with identical summary output.
- Evidence level: protocol/threat model may become `proven`; native containment/path primitives, packaged bridge and Authenticode remain pending.
- Failure fallback: block all native implementation and production launcher work; never replace the helper with direct Node spawn or a generic privileged bridge.
- Unlocks after Root acceptance: P1-NAT-002 and P1-NAT-003.
