# P0-ARC-003 — Tauri/Rust bounded stack spike

- Owner: `/root/installer_plan_review`
- Objective: determine whether a narrowly isolated Tauri/Rust control plane can satisfy Alpha installer/configurator needs using the same comparison contract as the Electron spike. This is evidence, not the final stack selection.
- Product boundary: the tool installs, detects, verifies, configures, compiles and hands off only. MiniMax H3 generates all video/native audio in ComfyUI only after the user clicks Run.
- Accepted inputs: `AGENTS.md`, ADR-001, accepted ADR-002, `docs/evidence/STACK_ELECTRON.md`, and `tasks/context/P0-ARC-002.md` as the comparison rubric.
- Allowed writes: `prototypes/phase0/stack-tauri/**`, `docs/evidence/STACK_TAURI.md`.
- Forbidden writes: root manifest/lockfile/build files, registry, schemas, main plan and other prototypes.
- Locks: none. All Cargo/npm/config/cache/output state must stay inside the isolated prototype where tools permit. Do not install or mutate a global Rust/Node/WebView toolchain.
- Required evidence: exact installed toolchain facts; build/test/package reproducibility; native path picker and Unicode/space path behavior; typed/allowlisted command surface; renderer/WebView isolation; safe argument-array owned-child launch without shell; cancellation/termination limits; Windows API/Job Object boundary; package size/startup/memory where measurable; accessibility; signing/MSIX/NSIS implications; updater absence; dependency inventory/SBOM and license/security scan.
- Comparison requirement: use the same fixtures/claims/categories as P0-ARC-002 and explicitly state where results are not comparable. Never infer a Tauri win from package size alone.
- Public evidence hygiene: reports and committed artifacts must not contain usernames, `X:\\Users\\...` private paths, credentials, tokens or raw environment dumps. Add a deterministic lint/test for this where practical.
- Acceptance: all commands supported by the existing local toolchains pass twice from the isolated project; unsupported build/package steps are reported as blocked with exact missing prerequisite rather than simulated. Report supported, unsupported, unresolved and production-only gates.
- Forbidden actions: no model/runtime download, GPU/H3 execution, Comfy/Desktop install, cloud inference, updater, telemetry, global package/toolchain mutation or user-file changes. Do not add a production “Run/generate video” surface.
- Failure fallback: preserve bounded reproducible evidence and mark Tauri unsuitable/conditional; do not broaden privileges or install global prerequisites.
- Unlocks after Root acceptance: P0-ARC-005 after P0-ARC-002 and P0-ARC-004 are also accepted.
