# Media capability probe

This package observes a verified managed PyAV runtime, an explicitly supplied private FFmpeg/FFprobe pair, and optionally supplied ambient host executables. It never downloads, installs, generates, queues, or processes media.

All actionable child commands are fixed plans executed through the trusted pre-first-instruction Job launcher as an absolute executable plus an argument array with `shell: false`. The launcher must prove the spawned image, loaded dependency tree, and a closed Job with no surviving descendants. Output, record counts, time, and process trees are bounded again at the probe boundary. Public results contain structured fields and exact catalog/artifact identities only; raw stdout, stderr, raw-output hashes, absolute paths, PIDs, timestamps, durations, environment values, and unredacted build paths are never returned. Configuration fingerprints cover only the sanitized public projection.

An ambient executable is observation-only and is always `selectable: false`. A private pair becomes selectable only after independent services verify the signed embedded catalog/build binding, each raw artifact hash and file identity, Authenticode signer identity, current ownership-ledger and handle containment/no-reparse proof, and every spawned image. The manifest's declarations are expected values, not verification proof. The default private verification services reject everything, so integration cannot accidentally bypass those gates.

PyAV metadata results describe observed API paths only. FFmpeg/FFprobe metadata results describe observed command-line mechanisms only. Neither is a claim that media sanitation or output has passed its separate file/GPU certification gate. The generic bounded process utility is internal attack-test infrastructure; on Windows it cannot prove a clean successful process tree and therefore cannot produce an actionable success result or probe ambient tools. Public ambient behavior is presence-only.
