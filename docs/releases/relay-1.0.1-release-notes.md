# Relay 1.0.1

Relay 1.0.1 是 Relay 1.0 的工作流投影修复版本，面向 Windows 10 / 11 x64，仅提供 Setup 安装包。

## 本次修复

- 修复专业导播编译请求被 IPC 严格校验误判为 `project has unexpected fields`：单镜头与多镜头的硬切/尾帧延续计划现在会经过同一闭集校验并原样交给编译器，不再在交接前被拒绝。
- Setup 安装完成页新增可取消的“运行 Relay”选项；它只启动 Relay 应用，不启动 ComfyUI、不提交队列，也不生成媒体。
- 修复旧项目中专业导播工作副本与项目权威镜头 ID 不一致时出现的“镜头与连续性状态不同步”：镜头文本、连续性、素材绑定、Take 和当前选中镜头会在载入时安全对齐，既有历史检查点保持不变。
- 专业导播草稿恢复异常改为项目内准确提示，不再把正常的本机环境检测误报为应用“初始化失败”。
- 专业导播绑定素材现在按认证模式真实投影：FL2VA 仅连接边界镜头首帧/尾帧，Ref2VA 稳定连接一至两张参考图片；T2V、视频、音频及动作参考会明确标为项目资料，不再显示假成功。
- ComfyUI 根工作流直接显示模式、20/25/8 步配置、基础种子和每镜种子；完整固定模型、采样器、调度器、降噪、FPS、原生音频与 Turbo 状态同时写入可审计工作流元数据。
- 硬切与尾帧延续产生不同的真实节点连线；开始/结束状态、继承字段、场景名称、实体资料和连续性按原文确定性进入对应镜头提示词。
- 快速创建和专业导播继续保持各自独立的提示词与素材输入；删除旧项目或切换项目不会复用旧提示词。
- 旧版通用素材引用会一次性迁移到明确首帧/尾帧槽；无法作为认证输入的引用保留为项目资料，不会静默丢失。
- 纯资料素材缺失只提示警告，不再阻断一个不读取该文件的 T2V 编译；真正进入 H3 的图片仍严格校验并在异常时阻断。
- Ref2VA 与 Turbo 安装说明、FFmpeg 用途已与真实编译能力统一。

## 工作流边界

Relay 只负责安装、检测、配置、项目与素材管理、确定性工作流编译及 ComfyUI 可编辑交接。Relay 不点击 Run、不调用 `/prompt`、不提交 ComfyUI 队列，也不生成视频或音频。

## 安装

- 安装包：`Relay-1.0.1-x64-Setup.exe`
- 文件大小：`100929265` 字节
- SHA-256：`79d0dbf954aa0e8150a08b8525032231747e356b8569732370fe50a5349706e3`
- 通过应用“关于”页检查更新，或从 `PlaTuring/Relay` 的 `v1.0.1` Release 下载。
- 若本机安装包的 SHA-256 与当前值不同，需要从同一 Release 重新下载安装；同版本热修复无法通过 SemVer 版本比较自动区分旧构建。
