# Relay 1.0.2

Relay 1.0.2 是面向 Windows 10 / 11 x64 的稳定维护版本，继续提供本机环境检测与配置、项目和素材管理、确定性 MiniMax H3 工作流编译，以及到 ComfyUI 的可编辑交接。

## 本次修复

- 补齐安装包中的本地运行时依赖，修复安装版执行检测时出现 `ERR_MODULE_NOT_FOUND` 的问题。
- 改进本机 ComfyUI 会话探测：先检查固定回环地址，短暂重试后才尝试启动受管实例，并提供可定位的超时、不可达和协议错误。
- 在未配置 FFmpeg 时增加 Windows 本机视频封面回退；无法取得真实封面时仍明确显示不可用，不生成伪缩略图。
- 专业导播的项目设置与高级参数保持展开，减少重复操作。
- “关于”页把 1.0 风格的开发者资料合并到“当前程序”卡片右侧，并使用发布者提供的标识；窄窗口下自动上下排列。资料区显示“独立开发者”“柏拉图灵 | PlaTuring”和“抖音 / B站：柏拉图灵”，链接列表只保留“项目仓库”，不再单列“GitHub”。
- 侧栏将“已生成视频”缩短为四字“视频成品”，避免窄侧栏换行或越界；页面功能和项目数据归属不变。

## 安装包

正式 Release 只提供 `Relay-1.0.2-x64-Setup.exe`。安装程序未使用 Authenticode 代码签名，Windows 可能显示未知发布者提示。GitHub 提供的资产摘要可用于核对文件完整性，但不代表发布者身份认证。

## 产品边界

Relay 不执行 MiniMax H3 推理，也不提交 ComfyUI 队列。实际视频与原生音频仍由用户在 ComfyUI 中明确启动后由 MiniMax H3 生成。
