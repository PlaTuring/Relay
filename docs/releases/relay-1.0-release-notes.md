# Relay 1.0

Relay 1.0 是面向 Windows 10 / 11 x64 的正式版本。内部版本号为 `1.0.0`，界面显示 `1.0`，GitHub Release 标签为 `v1.0.0`。

## 安装

- 本版本只提供 `Relay-1.0-x64-Setup.exe`，不提供 Portable。
- 请只从 `PlaTuring/Relay` 的公开 GitHub Release 下载。
- 应用内更新只在用户明确点击“下载并安装”后发生，并校验 GitHub Release 资产长度和 SHA-256 摘要；失败或取消不会启动安装程序。
- 验证通过后只启动该受管 Setup 的可见 Windows 安装界面，不传静默参数；启动成功后当前 Relay 才退出。

## 本次发布

- 新增当前项目“已生成视频”：Relay 可发现属于当前项目和工作流且已稳定写盘的 `SaveVideo` 输出。
- 新工作流使用不含项目名、提示词或本机路径的安全输出前缀；旧版通用前缀、自定义输出目录和改名视频可手动补录。
- 已生成视频可播放、显示所在目录，并可由用户明确复制加入项目素材库；原始 ComfyUI 输出保持不变。
- “画质超分（功能规划中）”页面只展示规划状态，不提供任何未实现按钮。
- “关于”页面使用固定 `PlaTuring/Relay` Stable Release 通道，只接受严格稳定 SemVer、唯一匹配的 Setup 资产、有效长度和 GitHub SHA-256 摘要；版本不一致时提供“下载并安装”。
- 满足稳定版本条件的最高版本候选如果元数据或资产不合格，Relay 会失败关闭，不回退到较旧版本。

## 升级说明

不具备应用内更新能力的早期版本仍需从 GitHub Releases 手动下载并运行 `Relay-1.0-x64-Setup.exe`；具备本合同的版本可在“关于”页点击“下载并安装”。

## 工作方式

Relay 提供安装、检测、配置、项目与素材管理、确定性工作流编译和 ComfyUI 可编辑交接。
