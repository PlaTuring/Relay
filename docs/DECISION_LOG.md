| D-022 | accepted | Relay 1.0 uses the fixed `PlaTuring/Relay` Stable Release channel. Only explicit user action may check or download; releases must be strict stable SemVer with `draft=false` and `prerelease=false`. The highest version satisfying those release/version conditions is selected first, then must contain exactly one contract-matching Setup with a positive length and GitHub REST SHA-256 digest. The main process validates length and digest and fails closed without older-version fallback. Installer launch is governed separately and only by D-023/ADR-016. | Product-owner authorization and ADR-015. This permits a narrow Stable Setup download without granting background update, arbitrary URL/path, or remote component/catalog authority. | Any background action, component mutation, channel/asset-contract expansion, arbitrary URL/path/digest IPC, rollback fallback, or publisher-identity claim. |
| D-023 | accepted | When a newer qualified Stable version exists, Relay may show “下载并安装”. Only that explicit click may download and validate the unique Setup, revalidate the exact managed non-reparse file, launch it interactively once with no arguments, and quit Relay only after Windows accepts the launch request. Failures keep Relay open. No renderer path/URL/command authority, background action, silent install or component mutation is allowed. | Product-owner authorization and ADR-016. This removes a redundant manual file-opening step while keeping the action bounded to a verified Stable Setup and visible Windows installer. | Any background/forced update, silent arguments, alternate executable/channel, arbitrary execution bridge, pre-launch quit, or claim that SHA-256 proves publisher identity. |
